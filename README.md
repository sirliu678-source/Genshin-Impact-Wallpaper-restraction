## 🌟 核心特性

- 🎮 **米哈游启动器媒体直链提取（专属支持）**：
  - 深度支持解析启动器本地缓存 `data_1` 等二进制数据文件。
  - 自动最短非贪婪匹配以 `http(s)://` 开头并以 `.webm`、`.webp`、`.png` 结尾的完整资源直链，精准剔除 Range 分片伪参数。
- 🖼️ **全格式动态小窗预览**：
  - 原生支持 **WebM 动效视频** 静音自动循环播放与悬停缩放。
  - 支持 **WebP、PNG、JPG、GIF** 等静态与动图直链小窗即时渲染。
  - 内置 `no-referrer` 与跨域容灾代理，穿透外链防盗链限制。
- ⚡ **提取板块独立筛选与批量导入**：
  - 支持按格式（WebM / WebP / PNG）与勾选状态多维度实时筛选。
  - 可勾选直接将提取到的资源批量同步至主画廊库中永久保存。
- ↶ **返回上一步（多级撤销容错）**：
  - 内置多步操作历史快照栈，支持误删、误添加、误重置后一键回退恢复。
  - 支持键盘快捷键 **`Ctrl + Z`**（Mac 为 **`Cmd + Z`**）一键撤销。
- 💾 **本地保存与一键批量操作**：
  - **单项下载**：卡片与全屏灯箱均支持一键下载保存媒体文件到本地。
  - **整库备份**：一键导出全量数据为 `.json` 文件，支持跨设备导入。
  - **批量打开**：支持多选模式或当前分类下一键在新标签页中批量打开。

## 📖 核心工作流：米哈游启动器壁纸提取与保存指南

只需 5 步，即可将米哈游启动器内展示的最新动态壁纸与角色插画批量提取、预览并下载：

1. **打开启动器日志目录**：
   - 打开米哈游启动器，点击右上角「设置」图标 ➔ 进入「关于」 ➔ 点击「查看客户端日志」。
2. **定位缓存文件夹**：
   - 在弹出的文件资源管理器中，点击进入 `1_1` 文件夹，依次进入子目录：
     ```text
     1_1 \ fedata \ Cache \ Cache_Data
     ```
3. **获取数据文件**：
   - 在 `Cache_Data` 目录下找到名为 **`data_1`** 的缓存文件。
4. **导入文档提取板块**：
   - 打开本项目网页，点击顶部的 **「⚡ 文档提取」** 版块。
   - 点击「选择本地文档上传」直接选中 `data_1` 文件（或将其直接拖拽至解析区域，亦可用记事本打开复制内容粘贴至文本框）。
   - 系统将自动过滤垃圾碎片，瞬间提取出以 `http` 开头、并以 `.webm` / `.webp` / `.png` 结尾的最短有效直链并生成小窗预览。
5. **入库与下载保存**：
   - **加入画廊库**：勾选想要保存的卡片，点击「📥 将已勾选网址加入原网址库」，数据将自动沉淀在本地画廊库中长期留存。
   - **直接下载/查看**：直接点击卡片上的「⬇ 下载」保存原画/视频文件到本地电脑，或点击「打开 ↗」在新窗口直接打开查看。
